# Cat sprites

The cat is the orange `catset` character, cropped and re-aligned to 48×48 frames
for Islet.

- Original sprite collection: **catset** by **seethingswarm** (CC0)
- Frames sourced from the orange cat directory in
  [Gheop/CATAI-Linux](https://github.com/Gheop/CATAI-Linux), which credits the
  catset sprites as CC0.
- The frames here are cropped to 48×48, with ground animations aligned to the
  bottom-center and the wall-grab peek aligned to the center. No other edits.

Animations included: idle, sit, walk, sneak, run, pounce, wall-grab peek,
surprised, butterfly chase, sleep, groom, stretch, yawn, love, greet, play,
loaf, wake, jump, land.
